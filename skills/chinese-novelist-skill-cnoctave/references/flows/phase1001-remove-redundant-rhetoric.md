# 第1001阶段：（可选）修辞手法去重优化

**在所有其他可选阶段之后执行**
**目标**：限制章节中比喻、拟人、排比、夸张等修辞手法的使用频次，以白描和对话为主的行文风格为标准，避免修辞手法重复雷同

> **定位**：此阶段在所有可选增强阶段（Phase 5-12、Phase 1000）完成之后最后执行。它只删减，不增补，因此结束后不再进行字数检查。

---

## 一、检查规则

### 1.1 修辞手法上限

| 修辞手法 | 每章上限 | 说明 |
|---------|---------|------|
| 比喻（明喻/暗喻/借喻） | 1 处 | 含"像""仿佛""如同""好似""宛如"等比喻词 |
| 拟人 | 1 处 | 赋予非人事物以人的特征 |
| 排比 | 1 处 | 三个或以上结构相似的短语/句子并列 |
| 夸张 | 3 处 | 超出事实的夸大表达 |
| 其他修辞手法 | 不检查 | 借代、对偶、反问、设问、双关、反复等 |

### 1.2 检测方式

逐章读取章节文件，扫描全文找出所有的修辞手法实例，按修辞类型归类计数。

```

  比喻：0 处（上限 1）✅
```

## 二、去重处理方式

### 2.1 处理原则

- **只删不增**：超标的多余修辞手法直接删除或改写为白描陈述，不新增任何内容
- **保留最精彩的一处**：同一修辞类型有多处时，保留效果最好的一处，删除其余
- **优先删后保留前**：同一章中多处超标时，优先删除靠后的实例，保留靠前的
- **改写为白描**：将修辞句改为平实的叙述或对话，保持原意不变

### 2.2 处理方法

| 修辞类型 | 超标处理方式 | 改写示例 |
|---------|-------------|---------|
| 比喻 | 删除或改为平实陈述 | "她的笑容像三月的春风" → "她笑了一下" |
| 拟人 | 删除或改为客观描写 | "风在耳边低语" → "风吹过耳边" |
| 排比 | 拆解为单一陈述 | "他跑过街道，穿过人群，越过障碍" → "他穿过拥挤的街道" |
| 夸张 | 缩减至 3 处以内 | "等了一万年" → "等了很久" |

### 2.3 操作流程

```
FOR 每一章(按章节编号从小到大):
  1. 读取章节文件内容
  2. 扫描全文，识别所有比喻/拟人/排比/夸张实例
  3. 按类型计数
  4. 若某类型超过上限：
     a. 从后往前遍历该类型的所有实例
     b. 逐个改写为白描或直接删除
     c. 每改一处重新计数，直到达标
  5. 写入修改后的章节文件
  6. 进入下一章
  继续直到所有章节处理完毕
```

### 2.4 改写规范

- **改写后不降低信息量**：删除修辞后，原句携带的事实信息（谁、做了什么、结果如何）必须保留
- **改写后保持风格一致**：改为白描后，行文风格须与上下文的叙事基调一致
- **不破坏悬念钩子**：若超标修辞位于章节结尾的悬念钩子中，优先删除/改写该章其他位置的多余修辞，保留钩子中的修辞不动
- **不破坏对话自然度**：角色对话中的修辞（如角色在说话时用了比喻）属于角色语言风格，不删改

### 2.5 对话中的修辞豁免

角色对话中出现的修辞手法属于角色语言风格，不计入上限，不做删改。

- 示例：角色说"你就像那天上的月亮，我够不着" → 这是角色台词，保留
- 示例：叙述句"月光像流水一样洒在她脸上" → 这是作者叙述语言，计入上限
